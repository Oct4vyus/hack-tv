# Installation

Home opens as an app and does not replace Samsung Smart Hub. It has been used successfully on a 2020 Samsung TV. The app requires Tizen 5.5 or newer; compatibility with other models and firmware versions is not guaranteed.

This guide assumes you've never installed an "unofficial" app on a Samsung TV before. Every technical term is explained the first time it appears. Follow the steps in order; don't skip any.

## Before you start: what you'll need

- **Python 3.9 or newer** on your computer. It runs this project's scripts.
- **Your computer and your TV on the same local network** (the same Wi-Fi or the same network cable). Use a trusted local network where the devices can communicate; a guest network or client isolation may prevent the connection.
- **The TV remote** within reach.
- To sign and install the final package you'll also need:
  - **Tizen Studio**: Samsung's official TV app development tool.
  - Inside Tizen Studio, the **TV Extension** and **Samsung Certificate Extension** (installed from its own package manager).
  - The `tizen` and `sdb` commands available from your terminal (i.e. on your `PATH`). The Tizen Studio installer usually offers to do this for you; say yes.
  - A **Samsung Developer account** (free, created at developer.samsung.com).
  - Your own signing certificates (explained below).

Always download the official builds for your OS (macOS, Windows, or Linux) and architecture (Intel/AMD or Apple Silicon). This guide hasn't been tested on every possible combination.

On Windows, use `python` instead of `python3` in every command in this guide. `deploy.sh` is a macOS/Linux shortcut; on Windows ignore it and run `python instalar.py` directly with the same options.

## Step 1 · Turn on Developer Mode on the TV

"Developer Mode" is a hidden setting that allows installing apps that don't come from Samsung's official store. Without it, the TV rejects any external app.

On the 2020 Samsung interface (the one used to test this project):

1. Go to **Apps** (the screen where you see Netflix, YouTube, etc.).
2. Using the remote, type **12345** (just the digits; some models open the panel automatically once you finish typing).
3. A panel opens. Set **Developer Mode** to **On**.
4. It will ask for a **Host PC IP**: enter **your computer's local IP** here (not the TV's). On macOS you'll find it under System Settings → Network; on Windows, run `ipconfig` in a terminal; on Linux, run `ip addr`.
5. Confirm and **restart the TV** when prompted.

Menus vary by model. If the panel does not appear, check **Apps → App Settings**, if available, and your model's documentation.

Separately, in the **TV's own network settings** (not your router's) note down the **TV's IP**. You'll need it in the next step. Don't confuse it with the computer IP you just entered.

## Step 2 · Connect your computer to the TV via SDB

**SDB** (Smart Development Bridge) is Samsung's tool for talking to a Tizen TV from the terminal — the Tizen-world equivalent of what ADB is for Android. It's included with Tizen Studio.

With the TV **on** and in Developer Mode, open a terminal on your computer and run this, **replacing `TV_IP_ADDRESS` with your TV's actual IP**:

```sh
sdb connect TV_IP_ADDRESS
sdb devices
```

If everything works, the second command prints a line with a serial number and the word `device`. **Copy that exact serial**: you'll need it again later, to install, uninstall, and debug.

The development port used by this flow is **26101**. You don't need to open anything on your router — the connection stays inside your local network. Never connect to a TV that isn't yours.

This project also includes an experimental client (`tools/minisdb.py`) that talks to that same port directly for one optional feature (listing your installed apps). It doesn't replace Certificate Manager or the official tools; it's just a shortcut for one specific step.

## Step 3 · Create your own signing certificates

Samsung TVs won't install any unsigned app, which is why you need your own certificates. You only do this **once** (the certificates get reused for future installs).

1. Open **Certificate Manager** inside Tizen Studio.
2. Create a new **Samsung → TV** profile.
3. The wizard will ask for an **author certificate** (generated by the tool itself) and a **distributor certificate**, which you need to tie to your TV's **DUID**. The DUID is a unique identifier for your television; Tizen Studio usually lets you fetch it by connecting to the TV (with SDB already connected, as in step 2) and requesting it from within the wizard itself, or you can find it under the TV's "About" settings.
4. Save the generated certificates and the password you choose **somewhere safe, outside this repository**. If you lose the author certificate, you won't be able to update the app later under the same identity.
5. If **Device Manager** shows a **Permit to install applications** option, enable it for your device: it's required to install the package once you sign it.

Don't share your Samsung Developer account, your DUID, or your certificates in public chats, screenshots, or repositories: they're tied to your developer identity and your specific device.

Each person installing Home should create their own certificate profile.

If you'd already installed an earlier version of Home signed with a different certificate, the new signature may prevent **updating** it: Tizen treats each author certificate as a distinct identity. If that happens, uninstall the old version before installing the new one (this removes any data stored by the app).

## Step 4 · Prepare the app package

From the project folder, run:

```sh
python3 instalar.py
```

This creates two local files (Git ignores them, so they're yours alone):

- `launcher/config.js`: your personal configuration.
- `launcher/apps.js`: an optional app list. Its default empty list lets Home discover visible apps through Tizen.

And it generates `build/Home-unsigned.wgt`: an **unsigned** package (`.wgt` is Tizen's package format, the equivalent of Android's `.apk`). This particular file **can't be installed yet** — it's just an intermediate check that everything copied correctly. The command doesn't download anything from the internet or connect to any TV.

### Customize what's shown

Open the newly created `launcher/config.js` in a text editor:

- `city: null` means the weather clock is disabled. To enable it, replace `null` with something like `{ name: "Barcelona", lat: 41.38, lon: 2.17 }`, using your own city's name and coordinates.
- `dock` is the list of apps shown in the first row, in that order. If there are more than five, Home automatically narrows the tiles to fit the screen.
- `show_all_apps: true` shows every app Tizen reports, including hidden and factory apps. Some can open tests, service menus, or reset functions; set it to `false` to use only the selected apps in `apps.js` and `samsung_apps`.
- `blocklist` still excludes names you specify when `show_all_apps: true`; for example, `blocklist: [/aging/i]` hides Aging Mode.
- `samsung_apps` accepts selected apps using `{ name: "Visible name" }` or `{ id: "ID", name: "Name" }`. Apps explicitly added by name can be shown even if the built-in filter would normally block them; the custom `blocklist` still applies.

The rest of your installed apps are detected automatically from what Tizen reports as visible. Run the preparation command again after changing your configuration.

Keep personal files out of `launcher/logos` and `launcher/glow`: the builder accepts only its listed assets and rejects symbolic links. Weather requests send your configured coordinates to Open-Meteo; see [Security and privacy](SECURITY.md).

### (Optional) Generate the app list manually

If the automatic listing doesn't reflect what you actually have installed, you can generate it yourself by connecting via SDB (with the TV already connected as in step 2):

```sh
python3 tools/panel_apps.py --tv TV_IP_ADDRESS
```

This is an experimental protocol built for this project, not an official Samsung API, so it may not work on every firmware. It generates a local `apps.js` with your app inventory. It is not required for installation. To restore automatic discovery, set `PANEL_APPS` to `[]` in `launcher/apps.js`, then rebuild the package.

### Sign the package

Once you have your certificate profile from step 3, run the script again, specifying that profile:

```sh
python3 instalar.py --profile "YOUR_PROFILE_NAME"
```

Replace `YOUR_PROFILE_NAME` with the exact name you gave the profile in Certificate Manager. Keep the quotes if the name contains spaces. The script:

1. Copies only the necessary files to `build/package`.
2. Internally calls `tizen package -t wgt -s PROFILE -- DIRECTORY` (Samsung's official signing command).
3. Checks that the resulting package contains both expected XML signatures before giving you the green light — though that check is only a local verification; the TV performs its own cryptographic validation when installing.

If it succeeds, you'll see a message confirming the **signed** `.wgt` is in `build/package`. From that point on, don't modify that file: any change would invalidate the signature.

## Step 5 · Install on the TV

With the serial you copied in step 2 and the same certificate profile:

```sh
python3 instalar.py --profile "YOUR_PROFILE_NAME" --target "YOUR_TV_SERIAL" --install
```

Internally, this runs `tizen install -n FILE -s SERIAL -- DIRECTORY` (the official install command). The script doesn't scan your network looking for TVs or pick a device for you — you have to specify the exact serial on purpose, to avoid accidentally installing on the wrong device. It also doesn't touch your certificate profiles.

If you prefer a shorter macOS/Linux shortcut, `./deploy.sh` accepts exactly the same arguments as `instalar.py`.

## Using the app

Open **Home** from the TV's Apps screen, like any other app. Navigate with the remote's arrows and confirm with OK. The remote's **Return** button closes Home and takes you back to where you were; the remote's **Home** button always takes you to Smart Hub, bypassing this app. If your model allows it, you can add Home to your shortcuts bar from the Apps menu itself.

Home does not automatically launch when the TV turns on; open it from Apps. See [Limitations](LIMITATIONS.md) for features that depend on your model or firmware.

## Uninstalling

```sh
python3 instalar.py --target "YOUR_TV_SERIAL" --desinstalar
```

You can also uninstall it directly with the remote: in Apps, select Home and use the **Remove** option. Be careful not to accidentally delete a different app from the list.

If you're done developing for now, it's a good idea to turn off Developer Mode (repeat step 1 and set **Developer Mode** to **Off**) and restart the TV, and manually revert any network setting you changed. Uninstalling Home doesn't undo any other setting or affect third-party tools you installed on your own (like TizenBrew).
